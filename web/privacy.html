Auto Language Switcher

Privacy

Last updated 2 September 2026 · applies to version 0.1.0

Auto Language Switcher collects nothing, transmits nothing, and has no server. Your messages are counted inside your browser and discarded. Everything it remembers is three small files on your own computer.

This page is written to be checked rather than believed. Every claim names the file that implements it.

What it reads

To choose a keyboard layout, the extension reads the messages already displayed in the conversation you have open, and counts letters by alphabet. It does not scroll, does not load history, and does not touch conversations you have not opened.

Reading a message produces numbers, not words:

reading  "מה נשמע אחי"
becomes  { "Hebrew": 9 }

The text exists only inside the function that counts it. What leaves the page is the count.

Outside the browser

It also works in applications you add yourself. This is where a keyboard switcher could quietly become something else, so: it reads nothing there. Not the text in the window, not what you type. Reading another application's contents needs accessibility interfaces; noticing that you are typing needs a keyboard hook, which is a keylogger. Neither is in the code, and a release check fails the build if either appears.

What it sees is which window is in front, and what it learns is the keyboard layout you chose while you were there. Only applications you add — one you have not added produces nothing at all, not even a note that it was open.

Window titles never reach your disk. They carry a channel, a person, a subject, a file path, so they are hashed with a random value created on your computer, exactly as conversation names are.

What it stores

Three files in %LOCALAPPDATA%\AutoLang, which you can open and read at any time.

FileContents
settings.jsonYour settings. No conversation data.
conversations.jsonA hashed key, the language you type there, and a date.
sites.jsonWhich sites you have paused.
apps.jsonThe applications you allowed, by process name.

A complete entry, nothing omitted:

{
  "9f2a4c8e1b3d5f7009f2a4c8e1b3d5f7": {
    "Mode": "Auto",
    "LastReliableLanguage": "Hebrew",
    "UpdatedAt": "2026-09-02T18:10:01Z"
  }
}

That is everything remembered about a conversation: you type Hebrew in it. No messages, no names, no numbers, no history.

Conversation names and phone numbers

WhatsApp identifies conversations by phone number. None is ever stored.

Before anything leaves the page, the identifier is hashed with SHA-256 and a random value created when you installed. The random value matters: without it, a hash of a phone number can be reversed by trying every number in a country, and the same contact would produce the same key on every machine in the world. With it, the file is meaningless anywhere but your computer.

The Windows program additionally refuses any key that is not already a hash, so the guarantee does not depend on the browser side behaving correctly.

What it never does

  • No network requests. No analytics, no telemetry, no update check, no error reporting. The extension holds no network permission and the code contains no HTTP client.
  • No account. Nothing to sign up for or sign in to.
  • No AI or cloud language service. Detection is a letter count against Unicode ranges, done locally.
  • No site you did not choose. Installing grants access to web.whatsapp.com and nothing else. Any other site is added by you from a button in the popup — one site, or all sites if you would rather not be asked again — and can be withdrawn the same way, which stops it reading immediately rather than at the next reload.
  • No password or payment fields. On any site, password boxes, payment-card fields and one-time-code fields are excluded outright. They are not read, not counted, and produce no signal of any kind.
  • No third parties. Nothing is shared, sold or disclosed, because nothing is collected.

Permissions

PermissionWhy it is needed
storageHolds the random value used for hashing. Nothing else.
nativeMessagingTalks to the Windows program. A browser extension cannot change a keyboard layout; only a native program can.
web.whatsapp.comReads the conversation you have open. The only site granted when you install.
scriptingStarts the same bundled script on a site you have allowed, and stops it when you withdraw that site. No remote or generated code is ever run.
activeTabLets the popup name the site you are on, so it can offer to enable it there. Limited to the tab in front, and only while the popup is open — unlike the tabs permission, which would expose every tab.
Any other siteOptional, and off until you click. Granted per site, or for all sites, from the popup. On a site you allow, it identifies the box you are typing in and counts letters by alphabet. Chrome will not grant either form without your click, and the popup always shows which state you are in.

<all_urls> is deliberately not requested, and no broad pattern is requested at install time. A release check enforces that: broad access has to sit in the optional list, where it means "the user may grant this", never in the required list, where installing would grant it silently.

Checking it yourself

Everything stored, in full:

type %LOCALAPPDATA%\AutoLang\*.json

Searching it for anything identifying, which returns nothing:

findstr /i "972 @c.us http" %LOCALAPPDATA%\AutoLang\*.json

For outbound requests, open chrome://extensions, click the extension's service worker, and watch the Network tab. It stays empty.

Deleting your data

Clear stored preferences in the tray menu or the extension's settings page deletes all three files immediately.

Uninstalling keeps them, because uninstalling is often a reinstall. Running the uninstaller with -RemoveData deletes those too.

Children

The product is not directed at children and collects no personal information from anyone, of any age.

Changes

If a future version ever collected or transmitted anything, that would be a change of what this product is, announced before release and requiring your consent. This page carries the date of its last change.
