Auto Language Switcher

The right keyboard, before you start typing.

You keep a supplier chat in English and a family chat in Hebrew. Windows does not remember which is which — so you find out you forgot only after a line of gibberish.

Free. Windows 10 and 11, Chrome and Edge. Hebrew, English, Russian, Arabic and Greek.

What it does

It reads which language you write in each conversation, and sets the layout when you switch to it. Not the language of the conversation — the language of your half of it.

That last row is the point. Below 70% confidence it changes nothing. Doing nothing costs you one keystroke; switching wrongly mid-sentence costs a deleted line.

It stays out of the way

  • Never switches while you are typing
  • Never touches a window that is not in front
  • Backs off for five minutes after you change the layout yourself
  • Pin any conversation to a language of your choosing and that beats everything
  • Selects the layout directly — it never cycles blindly through your languages

When it decides not to act, the popup says why in plain words, so it is never a mystery.

Nothing leaves your computer

There is no server to send anything to. No account, no telemetry, no update check — the extension has no network permission at all.

Messages are counted in the page and discarded. What reaches the rest of the product is a pair of numbers: 

reading  "מה נשמע אחי"
becomes  { "Hebrew": 9 }

Conversation names are phone numbers, so they are never stored. They are hashed with a random value created when you install, which makes the stored file meaningless on any other machine. The agent refuses anything that is not already hashed.

Installing

Two pieces, and they are separate for a reason: a browser extension cannot change your keyboard layout. Only a native program can ask Windows to do that.

1. The Windows agent

An 8.8MB download that switches the layout and remembers your preferences. Installs for your user account only — no administrator rights.

2. The browser extension

Installing it grants one site: web.whatsapp.com. Any other site is a button in the popup, approved by Chrome's own dialog and withdrawn from the same button — so the install itself asks for nothing beyond WhatsApp Web.

The languages you want it to use must already be added as Windows keyboard layouts — it switches between layouts you have and never installs one. Hebrew, English, Russian, Arabic and Greek; it tells them apart by alphabet, which is why those five and not more.

Questions

Does it read my messages?

It counts letters by alphabet in the conversation you have open, and discards the text in the same step. It never scrolls, never loads history, and never sees conversations you have not opened.

Why does it need a program installed?

Changing a keyboard layout is a Windows operation. No browser extension can do it, on any browser.

It picked English for a Hebrew message

If you write Hebrew in Latin letters — "ma nishma" — English is right. The question is which keys you are about to press, not which language you are speaking.

Which languages?

Hebrew, English, Russian, Arabic and Greek. Detection works on Unicode ranges, so a language qualifies when it has an alphabet of its own — which is also the honest limit: Spanish, French and German all use the Latin alphabet and cannot be told apart this way.

Other apps and sites?

Both, and they are already here. Any site you turn on from the popup, remembered per writing box — so a Hebrew message and an English search on one page stay separate. And applications you add in settings, remembered per window.

Outside the browser it reads nothing inside an application — not the text in the window, not what you type. It sees which window is in front and the layout you chose while you were there. Window titles are hashed before anything is stored, because they carry file paths and people's names. The privacy document says exactly why.
